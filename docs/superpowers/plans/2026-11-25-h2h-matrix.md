# Career H2H Matrix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Career head-to-head matrix on the home Managers tab.

**Architecture:** Pure `buildH2HMatrix` over matchup rows; Next route reads Turso and returns managers + cells; Rankings tab renders a scrollable heat grid.

**Tech Stack:** Next.js App Router, Drizzle/Turso, React Query, node:test

**Spec:** `docs/superpowers/specs/2026-11-25-h2h-matrix-design.md`

## Global Constraints

- No new database tables
- Include playoffs; exclude unfinished matchups
- Do not commit unless the user asks

## Review Focus

- Unfinished matchup counted as a game
- Self cell showing 0–0
- Manager not in rankings appearing as an axis
- Tie displayed without the third number
- Mobile clipping the name column while scrolling
